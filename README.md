# Aicart · Serena

Página informativa estática de Aicart, con diseño Serena.

## Estado

Portada implementada. Privacidad y condiciones son borradores explícitos pendientes de completar y revisar antes de su uso definitivo. No existe un dominio personalizado configurado.

## GitHub Pages

En Settings → Pages, seleccionar Deploy from a branch, rama main y carpeta / (root). El nombre del repositorio no determina el futuro dominio propio.

Sin dependencias, compilación, formularios, analítica ni JavaScript. El acceso privado enlaza al entorno de ensayo y mantiene su autenticación independiente.
